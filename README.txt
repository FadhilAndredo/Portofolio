PORTOFOLIO ANDREDO.DEV

Upload seluruh isi folder ini ke hosting atau GitHub Pages.
Versi ini merupakan website responsif biasa. Fitur pemasangan PWA dan caching offline telah dihapus.
Untuk pengujian lokal: python -m http.server 8000
Buka http://localhost:8000

PENGGUNA VERSI LAMA
Pertahankan sw.js yang disertakan saat mengganti file di hosting. File tersebut hanya untuk menonaktifkan service worker dan cache portofolio versi lama; tidak menyediakan fitur PWA.

FOTO PENGALAMAN
Tambahkan foto sendiri ke folder images dengan nama:
- pengalaman-nashta.jpg
- pengalaman-kampus-mengajar.jpg
Placeholder otomatis berganti dengan foto ketika file tersedia. Atur crop dengan object-position pada .experience-photo>img jika diperlukan.

SERTIFIKAT
Empat gambar sertifikat belum disertakan di unggahan awal.
Salin gambar lama ke folder images: EIT2.jpg, DA.jpg, JS.jpg, PY.jpg.
Tautan kredensial asli tetap tersedia tanpa gambar.

TEMA DAN ANIMASI
Tema awal mengikuti perangkat, pilihan disimpan di browser.
Nama menggunakan font Caveat; animasi menulis berulang ketika nama keluar lalu masuk kembali ke layar.
Foto profil menggunakan cutout transparan tanpa latar atau bingkai.
Sapaan waktu dihapus. Ukuran teks dan gelembung kompetensi diperbesar.
Kompetensi mengambang dekat foto pada desktop maupun ponsel; ukuran dan jaraknya menyesuaikan layar.
Latar memakai aksen organik dan titik sederhana mengikuti tema; nama memiliki warna dan garis tepi kontras.
Tombol navigasi sertifikat berada dalam baris tersendiri di bawah deskripsi.
Animasi mengikuti preferensi kurangi gerakan.
Font dan ikon eksternal memerlukan internet pada pemuatan pertama; fallback teks tetap tersedia.

Tidak ada service worker baru yang didaftarkan oleh website ini.
